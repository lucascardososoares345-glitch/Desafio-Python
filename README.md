# Desafio Python — Sistema Bancário

Simulação de operações bancárias em um programa de terminal, desenvolvida como exercício de lógica de programação e organização de funções em Python.

## Funcionalidades

- Depósitos, saques e consulta de extrato.
- Validação de saldo, valor, limite por saque e quantidade de saques.
- Cadastro de usuários, com verificação de CPF duplicado.
- Criação e listagem de contas vinculadas a usuários.

## Tecnologias e conceitos

Python 3, funções, condicionais, laços, listas, dicionários e argumentos posicionais e nomeados.

## Execução

Não são necessárias bibliotecas externas para o script atual.

```bash
git clone https://github.com/lucascardososoares345-glitch/Desafio-Python.git
cd Desafio-Python
python .py
```

Use o menu do terminal para realizar operações. O arquivo original do exercício se chama `.py`.

## Escopo e limitações

Projeto educacional: os registros ficam em memória e são perdidos ao encerrar o programa. Não possui autenticação, integração bancária nem persistência de dados. O saldo e o extrato são globais na implementação atual, não separados por conta. Entradas numéricas inválidas ainda podem gerar erros. Utilize somente dados fictícios durante os testes.
